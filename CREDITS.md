# Data, font and audio credits

- Quran text metadata and QCF V2 glyph data are generated from the Quran Foundation / Quran.com Content API v4 using Mushaf ID 1 (QCF V2).
- The 604 page-specific QCF V2 fonts and Uthmanic Hafs Unicode font are served by the Quran Foundation font CDN.
- QCF/Unicode font bundling and caching are subject to Quran Foundation's Developer Terms. Before distributing the app, maintain the required active Developer Console account and include the attribution: **Quran fonts provided by Quran Foundation.**
- Ayah recitation audio is streamed and downloaded on demand from the Al Quran Cloud audio CDN at cdn.islamic.network. The app stores the user's explicitly downloaded ayah clips in its private document directory for offline playback.
